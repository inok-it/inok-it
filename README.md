# Inok // Systems & Infrastructure

Focusing on Linux server hardening, container orchestration, and high-performance web architecture. I design and maintain self-hosted environments built on Zero Trust principles, automated disaster recovery, and strict edge security.

### Architecture & Tech Stack

* **OS & Hardening:** Ubuntu Server,UFW, Fail2Ban, SSH Key/FIDO2 Auth, Lynis Auditing
* **PaaS & Containers:** Docker, Coolify, Traefik (Reverse Proxy), Docker, Authentik (SSO / ForwardAuth)
* **Edge & Storage:** Cloudflare (WAF, DNSSEC, Strict TLS, R2 Object Storage)
* **Observability:** Uptime Kuma, Dozzle, Diun, ntfy (Push Alerts), Umami Analytics
* **Web & CMS:** Astro, Preact, Native CSS, WordPress / WooCommerce
